# 스왑 인/아웃

메모리 스왑핑은 물리 메모리 사용을 극대화하기 위한 메모리 회수 기법입니다. 주기억장치의 프레임이 모두 할당되면 시스템은 더 이상 사용자 프로그램의 메모리 할당 요청을 처리할 수 없습니다. 한 가지 해결책은 현재 사용되지 않는 메모리 프레임을 디스크로 스왑아웃하여 다른 애플리케이션에서 사용할 수 있도록 메모리 자원을 확보하는 것입니다.

스왑은 운영체제가 수행합니다. 시스템이 메모리 부족을 감지하면 스왑 디스크로 추방할 페이지를 선택하고, 해당 물리 프레임의 내용을 디스크에 복사합니다. 프로세스가 스왑아웃된 페이지에 접근하면 운영체제는 내용을 다시 메모리로 불러와 페이지를 복원합니다.

추방 대상으로 선택된 페이지는 익명 페이지이거나 파일 기반 페이지일 수 있습니다. 이 절에서는 각 경우를 처리하는 방법을 설명합니다.

모든 스왑 연산은 직접 호출되는 함수가 아니라 페이지 타입별로 등록된 함수 포인터를 통해 호출됩니다. 이 함수 포인터들은 각 페이지의 초기화자에 등록되는 `struct page_operations`의 멤버로 포함됩니다.

## 익명 페이지(Anonymous Page)
`vm/anon.c`의 `vm_anon_init`과 `anon_initializer`를 수정하세요. 익명 페이지는 백업 저장소가 없으므로 익명 페이지의 스왑을 지원하기 위해 스왑 디스크(swap disk)를 사용합니다. 익명 페이지의 스왑을 구현할 때 이 스왑 디스크를 활용하세요.

```c
void vm_anon_init (void);
```
이 함수에서는 스왑 디스크를 초기화해야 합니다. 또한 스왑 디스크의 빈 영역과 사용 중인 영역을 관리할 자료구조를 마련해야 합니다. 스왑 영역은 페이지 크기(`PGSIZE`, 4096 바이트) 단위로 관리합니다.

```c
bool anon_initializer (struct page *page, enum vm_type type, void *kva);
```
익명 페이지의 초기화자입니다. 스왑을 지원하기 위해 `anon_page`에 몇 가지 정보를 추가해야 합니다.

`vm/anon.c`에서 `anon_swap_in`과 `anon_swap_out`을 구현하여 익명 페이지의 스왑을 지원하세요. 페이지를 스왑인하려면 먼저 스왑아웃된 상태여야 하므로 `anon_swap_out`을 먼저 구현하는 것이 좋습니다. 메모리 내용을 스왑 디스크로 이동시키고, 필요 시 다시 메모리로 복원해야 합니다.

```c
static bool anon_swap_in (struct page *page, void *kva);
```
스왑 디스크에서 익명 페이지를 스왑인하여 디스크의 데이터를 메모리로 읽어옵니다. 데이터 위치(스왑 슬롯)는 페이지가 스왑아웃될 때 페이지 구조체에 저장되어야 합니다. 스왑 테이블(스왑 슬롯 관리)을 업데이트하는 것을 잊지 마세요(스왑 테이블 관리는 앞의 섹션 참조).

```c
static bool anon_swap_out (struct page *page);
```
익명 페이지를 스왑 디스크로 스왑아웃합니다. 스왑 테이블을 사용하여 디스크에서 빈 스왑 슬롯을 찾고, 페이지의 데이터를 해당 슬롯에 복사합니다. 데이터의 위치는 페이지 구조체에 저장되어야 합니다. 더 이상 빈 슬롯이 없다면 커널을 패닉할 수 있습니다.

## 파일 매핑 페이지(File-Mapped Page)
파일 기반 페이지의 내용은 파일에서 오므로, 매핑된 파일 자체가 백업 저장소 역할을 합니다. 즉, 파일 기반 페이지를 추방할 때는 해당 매핑의 파일로 내용을 다시 써야 합니다. `vm/file.c`에서 `file_backed_swap_in`과 `file_backed_swap_out`을 구현하세요. 필요에 따라 `file_backed_init`과 `file_initializer`를 수정할 수 있습니다.

```c
static bool file_backed_swap_in (struct page *page, void *kva);
```
파일에서 내용을 읽어와 `kva`에 해당 페이지를 스왑인합니다. 파일 시스템과의 동기화가 필요합니다.

```c
static bool file_backed_swap_out (struct page *page);
```
페이지 내용을 파일로 다시 쓰면서 스왑아웃을 수행합니다. 먼저 페이지의 더티(dirty) 비트를 확인하여, 더티가 아니라면 파일을 수정할 필요가 없습니다. 스왑아웃한 후에는 페이지의 더티 비트를 꺼야 합니다。
